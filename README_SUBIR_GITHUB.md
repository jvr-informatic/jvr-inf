# JVR-INFORMATIC - versión corregida para GitHub Pages

Esta copia está preparada para publicarse desde la rama `main` y la carpeta `/ (root)`.

## Importante
El video `CURSO DE CAJERO.mp4` fue retirado porque GitHub no permite subir archivos individuales de más de 25 MB mediante la interfaz web. La tarjeta de la galería ahora abre `Captura.JPG` como imagen, por lo que la página puede publicarse completa sin ese archivo pesado.

## Publicación
Subir el contenido de esta carpeta al repositorio `jvr-informatic/jvr-inf`, manteniendo `index.html` en la raíz y la carpeta `assets` completa.

En GitHub Pages usar:
- Branch: `main`
- Folder: `/ (root)`

Después de publicar, abrir:
https://jvr-informatic.github.io/jvr-inf/

Si el navegador muestra una versión antigua, usar `Ctrl + F5`.
