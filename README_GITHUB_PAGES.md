# JVR-INFORMATIC — GitHub Pages

Versión preparada para publicar como sitio estático en GitHub Pages.

## Publicación
1. Crear un repositorio público en GitHub.
2. Subir **todo el contenido de esta carpeta** a la raíz del repositorio.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir la rama `main` y la carpeta `/ (root)`.
6. Guardar y esperar la publicación.

## Importante
GitHub Pages no ejecuta PHP ni MySQL. El formulario de contacto fue adaptado para abrir WhatsApp, por lo que esta versión no depende de `forms/contact.php`.

La página principal es `index.html`. Se incluyen las imágenes, videos, estilos, scripts, galería y librerías locales necesarias.
